QRLink 🚀
Create smart QR codes. Shorten links. Track everything.

QRLink is a modern URL shortener and dynamic QR code platform built with Next.js and deployed on Vercel. It enables users to generate short links, create dynamic QR codes, manage redirects, and analyze engagement through real-time analytics.

Features
🔗 URL Shortening
📱 Dynamic QR Code Generation
📊 Click & Scan Analytics
🎯 Custom Redirect Destinations
🔒 Secure Link Management
⚡ Fast Edge Deployment with Vercel
🎨 Modern Responsive UI
👤 User Authentication
📈 Dashboard for Link Performance
Tech Stack
Next.js
TypeScript
Tailwind CSS
Vercel
PostgreSQL
Prisma ORM
NextAuth/Auth.js
Getting Started
Clone the repository
git clone https://github.com/yourusername/qrlink.git
cd qrlink
Install dependencies
npm install
Configure environment variables
Create a .env.local file:

DATABASE_URL=
NEXTAUTH_SECRET=
NEXTAUTH_URL=http://localhost:3000
Run development server
npm run dev
Visit:

http://localhost:3000
